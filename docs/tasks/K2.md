# [K2] Adım 2 – Özellik çıkarımı (features.parquet)

**Sahibi:** K2 · **Son tarih:** 30 Kas · **Dal:** `feat/features`
**Girdi:** `data/processed/windows.npz` (`X_clean` (N, 32, 12), `channels`) + `windows_meta.csv`
**Çıktı:** `data/processed/features.parquet` + `docs/features.md`

### Yapılacaklar
- [ ] `src/gait/features/time_domain.py`: mean, std (ddof=1), var, rms, CoV [%], asimetri indeksi
- [ ] `src/gait/features/freq_domain.py`: güç spektrumu (ortalama çıkarılmış), baskın frekans (DC hariç), normalize spektral entropi
- [ ] `src/gait/features/build.py → extract_features`: hepsini `<kanal>__<özellik>` adlarıyla birleştir; asimetri için `asym__<sol>__<sağ>`
- [ ] `python scripts/run_step2.py` → `features.parquet`
- [ ] `docs/features.md`: her özelliğin formülü, birimi, klinik anlamı (örn. HD'de adım CoV'si yüksek)
- [ ] (Bonus) `X_clean` vs `X_filt` ile özellik dağılımlarını karşılaştıran kısa not: filtre CoV'yi ne kadar düşürüyor?

### Kabul kriterleri
- `pytest tests/test_contract_k2_features.py` → **hiç SKIP yok, hepsi geçiyor**
- 12 kanal × 7 özellik + 3 asimetri = 87 özellik sütunu (+3 kimlik sütunu), NaN/inf yok
- Satır sayısı = pencere sayısı; `window_idx` meta ile birebir
- Fonksiyonlar vektörize (döngüsüz numpy); tüm veri seti < 5 s

### Tuzaklar
- FFT'den önce ortalamayı çıkarmazsan baskın frekans hep 0 çıkar.
- Sabit sinyalde entropi 0/0 → 0 tanımla (testte var).
- Ölçekleme YAPMA: K3'ün Pipeline'ı yapar (aksi hâlde test fold'u bilgisi sızar).
